# Integrative Health Intelligence — Public Prototype

A portfolio-ready static website and interactive product prototype.

## Structure
- `index.html` — landing page, product case study, evidence model, interactive 9-step demo
- No build system or external dependencies required.

## Important boundary
This is a product/portfolio prototype, not a clinical tool, medical device, diagnosis engine, or medical advice service.

## Evaluation
The project includes a separate 30-case evaluation fixture and deterministic reference baseline. Baseline results must not be described as clinical validation or production AI performance.
