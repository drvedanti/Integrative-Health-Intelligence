# Engine Evidence Boundary

The portfolio now contains an executable **reference engine** so the evaluation pipeline has a real implementation to run.

Important distinction:

- **Reference engine:** deterministic rules, transparent, inspectable.
- **LLM/model:** not yet evaluated.
- **Clinical validation:** not performed.
- **30/30 policy result:** baseline conformance to the fixture-specific checks only.

Do not present the 30/30 result as an AI accuracy, safety, or clinical-performance score.
